# Обязательные задания лаборатории

В этой папке находятся требования к обязательным заданиям курса. Каждый файл `task-N.md` описывает отдельное задание с критериями приёмки.

Общие правила выполнения
- Работы должны быть собственными: не копируйте чужие решения полностью. Короткие отрывки кода допустимы при явном указании источника.
- Перед сдачей убедитесь, что вы добавили комментарии/ссылки на внешние ресурсы, если использовали их.
- В репозитории не храните секреты. Используйте `.env*` файлы, которые игнорируются git-ом.

Порядок работы
1. Прочитайте `task-1.md` и выполните его. По завершении переходите к `task-2.md` и т.д.
2. Каждый таск содержит минимальный набор файлов / тестов, которые должны пройти.

Файлы заданий:
- `task-1.md` — шаблон бота и тестовый режим (минимально: `/start`).
- `task-2.md` — конфигурация и API-клиент для LMS.
- `task-3.md` — интеграция LLM-инструментов (описания инструментов + вызовы).
- `task-4.md` — сетевая проверка и Docker (контейнеры общаются через сервисные имена).

Если у вас есть вопросы по содержанию задания — задавайте конкретно: какой файл не проходит тест, какой лог содержит ошибку и т.д.
