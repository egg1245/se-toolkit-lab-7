DESIGN DECISIONS DOCUMENTED
================================================================================

Why Pure Handlers?
  - Testable without Telegram API
  - Reusable from CLI, tests, or production bot
  → See bot/PLAN.md

Why Async httpx?
  - Prepares for concurrent API calls
  - Better performance than sync requests
  → See bot/README.md

Why Tool Descriptions (not regex)?
  - True LLM routing based on descriptions
  - Matches production LLM APIs
  - If wrong → improve description, not code
  → See lab/tasks/required/task-3.md

Why Service Names in Docker?
  - Services find each other on network
  - localhost inside container = container's loopback
  → See lab/tasks/required/task-4.md
